# Technical Design Document

## Overview

Shareable Program Templates adds the ability for users to publish training programs as public, read-only templates that can be browsed, previewed via deep link, and cloned into another user's program library. The implementation spans a Supabase migration (two new tables + RLS), a service layer for publish/clone/browse operations, a slug-generation utility, and three new Expo Router screens.

### Key Architectural Decisions

1. **JSONB Snapshot (frozen at publish time)** — The template stores a complete copy of the program structure as JSONB. This decouples the template from the source program, so subsequent edits to the original never affect published templates. Trade-off: storage duplication vs referential integrity complexity.

2. **Slug with collision suffix** — Slugs are generated by slugifying the title. On collision, a random 4-character alphanumeric suffix is appended (separated by `-`). This keeps URLs human-readable while guaranteeing uniqueness.

3. **Cursor-based pagination** — The browse screen uses cursor-based pagination keyed on `created_at` (descending) + `id` for tie-breaking. This avoids offset drift when new templates are published.

4. **Clone as transaction** — The clone operation parses the JSONB snapshot and inserts `program` → `program_days` → `program_day_items` within a single Supabase RPC to guarantee atomicity.

5. **RLS for access control** — Public SELECT on `program_templates` where `is_published = true`, author-only mutations, and authenticated-only INSERT on `template_clones`.

```sql
);

CREATE INDEX idx_program_templates_author_id ON program_templates(author_id);
CREATE INDEX idx_program_templates_published ON program_templates(created_at DESC)
  WHERE is_published = true;
CREATE INDEX idx_program_templates_slug ON program_templates(slug)
  WHERE is_published = true;
CREATE INDEX idx_program_templates_tags ON program_templates USING gin(tags);

-- template_clones table
CREATE TABLE template_clones (
  id uuid PRIMARY KEY DEFAULT gen_random_uuid(),
  template_id uuid NOT NULL REFERENCES program_templates ON DELETE CASCADE,
  user_id uuid NOT NULL REFERENCES auth.users ON DELETE CASCADE,
  cloned_at timestamptz NOT NULL DEFAULT now()
);

CREATE INDEX idx_template_clones_template_id ON template_clones(template_id);
CREATE INDEX idx_template_clones_user_id ON template_clones(user_id);

-- RLS policies
ALTER TABLE program_templates ENABLE ROW LEVEL SECURITY;
ALTER TABLE template_clones ENABLE ROW LEVEL SECURITY;

-- Anyone can read published templates
CREATE POLICY "Public read published templates"
  ON program_templates FOR SELECT
  USING (is_published = true);

-- Author can do everything on their own templates
CREATE POLICY "Author manages own templates"
  ON program_templates FOR ALL
  USING (auth.uid() = author_id)
  WITH CHECK (auth.uid() = author_id);

-- Authenticated users can insert their own clone records
CREATE POLICY "Authenticated insert own clones"
  ON template_clones FOR INSERT
  WITH CHECK (auth.uid() = user_id);

-- Anyone can read clone records (for aggregate counts)
CREATE POLICY "Public read clones"
  ON template_clones FOR SELECT
  USING (true);
```

### 2. Slug Generator

**File:** `src/utils/slug-generator.ts`

```typescript
/**
 * Generates a URL-safe slug from a title string.
 * If a collision checker returns true, appends a random 4-char suffix.
 * Max slug length: 64 characters.
 */

const MAX_SLUG_LENGTH = 64;
const SUFFIX_LENGTH = 4;
const SUFFIX_CHARS = 'abcdefghijklmnopqrstuvwxyz0123456789';

export function slugify(title: string): string {
  return title
    .toLowerCase()
    .normalize('NFD')
    .replace(/[\u0300-\u036f]/g, '') // strip diacritics
    .replace(/[^a-z0-9\s-]/g, '')   // remove non-alphanumeric
    .replace(/[\s_]+/g, '-')         // spaces/underscores to hyphens
    .replace(/-+/g, '-')             // collapse consecutive hyphens
    .replace(/^-|-$/g, '')           // trim leading/trailing hyphens
    .slice(0, MAX_SLUG_LENGTH);
}

export function generateRandomSuffix(): string {
  let suffix = '';
  for (let i = 0; i < SUFFIX_LENGTH; i++) {
    suffix += SUFFIX_CHARS[Math.floor(Math.random() * SUFFIX_CHARS.length)];
  }
  return suffix;
}

export function appendSuffix(baseSlug: string, suffix: string): string {
  const maxBase = MAX_SLUG_LENGTH - SUFFIX_LENGTH - 1; // -1 for the separator
  const trimmedBase = baseSlug.slice(0, maxBase);
  return `${trimmedBase}-${suffix}`;
}

export async function generateUniqueSlug(
  title: string,
  existsCheck: (slug: string) => Promise<boolean>
): Promise<string> {
  const base = slugify(title);

  if (!(await existsCheck(base))) {
    return base;
  }

  // Collision — append random suffix
  let slug: string;
  let attempts = 0;
  do {
    slug = appendSuffix(base, generateRandomSuffix());
    attempts++;
    if (attempts > 10) {
      // Extremely unlikely — use timestamp fallback
      slug = appendSuffix(base, Date.now().toString(36).slice(-SUFFIX_LENGTH));
      break;
    }
  } while (await existsCheck(slug));

  return slug;
}
```

### 4. Clone RPC (Atomic Transaction)

**File:** `supabase/migrations/2025XXXXXXXX_clone_template_rpc.sql`

```sql
CREATE OR REPLACE FUNCTION clone_template(
  p_user_id uuid,
  p_template_id uuid
)
RETURNS uuid
LANGUAGE plpgsql
SECURITY DEFINER
AS $$
DECLARE
  v_snapshot jsonb;
  v_program_id uuid;
  v_day_id uuid;
  v_day jsonb;
  v_item jsonb;
  v_template_title text;
BEGIN
  -- Get the template snapshot
  SELECT program_snapshot, title INTO v_snapshot, v_template_title
  FROM program_templates
  WHERE id = p_template_id AND is_published = true;

  IF NOT FOUND THEN
    RAISE EXCEPTION 'Template not found or not published';
  END IF;

  -- Create the program
  INSERT INTO programs (user_id, name, status)
  VALUES (p_user_id, v_snapshot->>'name', 'draft')
  RETURNING id INTO v_program_id;

  -- Create program_days and their items
  FOR v_day IN SELECT * FROM jsonb_array_elements(v_snapshot->'program_days')
  LOOP
    INSERT INTO program_days (program_id, day_number, name)
    VALUES (
      v_program_id,
      (v_day->>'day_number')::integer,
      v_day->>'name'
    )
    RETURNING id INTO v_day_id;

    FOR v_item IN SELECT * FROM jsonb_array_elements(v_day->'items')
    LOOP
      INSERT INTO program_day_items (
        program_day_id, type, "order",
        exercise_id, target_sets, target_reps,
        target_weight, target_rpe, timer_config, notes
      )
      VALUES (
        v_day_id,
        v_item->>'type',
        (v_item->>'order')::integer,
        CASE WHEN v_item->>'exercise_id' IS NOT NULL
          THEN (v_item->>'exercise_id')::uuid ELSE NULL END,
        (v_item->>'target_sets')::integer,
        v_item->>'target_reps',
        CASE WHEN v_item->>'target_weight' IS NOT NULL
          THEN (v_item->>'target_weight')::numeric ELSE NULL END,
        CASE WHEN v_item->>'target_rpe' IS NOT NULL
          THEN (v_item->>'target_rpe')::numeric ELSE NULL END,
        CASE WHEN v_item->'timer_config' IS NOT NULL
          THEN v_item->'timer_config' ELSE NULL END,
        v_item->>'notes'
      );
    END LOOP;
  END LOOP;

  -- Record the clone
  INSERT INTO template_clones (template_id, user_id)
  VALUES (p_template_id, p_user_id);

  -- Increment clone count
  UPDATE program_templates
  SET clone_count = clone_count + 1, updated_at = now()
  WHERE id = p_template_id;

  RETURN v_program_id;
END;
$$;
```

## Error Handling

| Scenario | Error Code | User-Facing Message | Recovery |
|----------|-----------|---------------------|----------|
| Program not found during publish | NOT_FOUND | "Program not found" | — |
| User not program owner | UNAUTHORIZED | "Only the program owner can publish" | — |
| Template slug generation fails (10+ collisions) | DB_ERROR | "Failed to create template, please try again" | Retry |
| Template not found by slug | NOT_FOUND | "Template not found" | Show not-found screen |
| Clone RPC fails | DB_ERROR | "Failed to clone template" | Retry button |
| Unauthenticated clone attempt | UNAUTHORIZED | — | Redirect to login |
| Empty title during publish | VALIDATION_ERROR | "Title is required" | — |
| Network failure during browse | DB_ERROR | "Unable to load templates" | Pull-to-refresh |

## Performance Considerations

- **Partial index** on `program_templates(created_at DESC) WHERE is_published = true` eliminates unpublished rows from browse queries.
- **GIN index** on `tags` column enables fast array containment queries for tag filtering.
- **Cursor-based pagination** avoids the performance penalty of high-offset queries.
- **Denormalized `clone_count`** avoids a COUNT query on `template_clones` for every card render.
- **JSONB snapshot** means preview rendering requires no joins — a single row fetch is sufficient.

## Testing Strategy

### Unit Tests
- Slug generation: specific examples for edge cases (empty title, all-special-characters, exactly 64 chars)
- Snapshot building: verify known program structures produce expected JSONB
- Auth guard logic: unauthenticated user gets redirected

### Property Tests (fast-check, 100+ iterations each)
- Slug invariants: generated slugs are always URL-safe, unique, and ≤64 chars
- Publish faithfulness: snapshot always matches source program structure
- Clone round-trip: cloned program matches snapshot
- Tag filtering: results always contain a matching tag
- Browse ordering: results are always sorted by created_at desc

### Integration Tests
- RLS policies: verify anonymous read access, author-only writes, authenticated clone insert
- Clone RPC: end-to-end clone against real Supabase instance
- Deep link routing: verify `/t/[slug]` renders preview screen

## Correctness Properties

*A property is a characteristic or behavior that should hold true across all valid executions of a system — essentially, a formal statement about what the system should do. Properties serve as the bridge between human-readable specifications and machine-verifiable correctness guarantees.*

### Property 1: Publish snapshot faithfulness

*For any* valid program (with any number of days and items), publishing it as a template SHALL produce a `program_snapshot` JSONB that contains the same program name, the same number of program_days (each with correct day_number and name), and the same program_day_items (each with matching type, order, exercise_id, target_sets, target_reps, target_weight, target_rpe, timer_config, and notes), and the template's `author_id` SHALL equal the publishing user's ID.

**Validates: Requirements 1.1, 1.4**

### Property 2: Slug generation invariants

*For any* title string, the generated slug SHALL be URL-safe (containing only lowercase alphanumeric characters and hyphens), SHALL have a maximum length of 64 characters, and SHALL be unique among all existing slugs (including when a collision suffix is appended).

**Validates: Requirements 1.2, 1.3**

### Property 3: Unpublished template exclusion

*For any* set of program templates where some have `is_published = false`, querying published templates (browse or slug lookup) SHALL never return a template where `is_published = false`.

**Validates: Requirements 2.2**

### Property 4: Clone round-trip fidelity

*For any* published program template with a valid `program_snapshot`, cloning it SHALL produce a new program with status "draft" whose structure (program name, day count, day names, day_numbers, and all item fields) matches the snapshot content exactly.

**Validates: Requirements 4.1**

### Property 5: Clone operation side effects

*For any* successful clone operation, the `template_clones` table SHALL contain exactly one new record with the correct `template_id` and `user_id`, and the template's `clone_count` SHALL have incremented by exactly 1.

**Validates: Requirements 4.2, 4.3**

### Property 6: Browse ordering and pagination

*For any* set of published templates, the browse query SHALL return results ordered by `created_at` descending, with at most `limit` (default 20) items per page, and subsequent cursor-based pages SHALL not contain duplicates or skip entries.

**Validates: Requirements 5.1**

### Property 7: Tag filter correctness

*For any* search term and set of published templates, filtering by tag SHALL return only templates where at least one tag contains the search term (case-insensitive), and SHALL never exclude a template that has a matching tag.

**Validates: Requirements 5.3**

### Property 8: Snapshot immutability

*For any* program that has been published as a template, modifying the original program (changing name, adding/removing days or items) SHALL NOT alter the `program_snapshot` stored in the template record.

**Validates: Requirements 6.3**
